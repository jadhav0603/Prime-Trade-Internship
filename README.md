# Prime-Trade-Internship

Task Management System

This project is a simple Task Management System built using MERN Stack.
Users can register, log in, create tasks, update them, and delete them.
Admin users can view all tasks and manage them.

Features - 
1. User authentication (Login/Register)
2. Role-based access (User & Admin)
3. Add, Edit, Delete tasks
4. Admin can view tasks created by all users
5. Protected routes using JWT
6. Responsive UI (React + Tailwind + Vite)

Tech Stack - 
Frontend: React, Vite, Tailwind CSS
Backend: Node.js, Express.js, MongoDB, JWT
Deployment: Render
